# AntMinerTab - 矿机与智能插座工业级监控套件

专为蚂蚁水冷矿机（`10.8.1.86`）与米家智能插座 3（`10.8.1.110`）深度定制的纯方形极简工业风监控与保护程序。

---

## 1. 核心功能与安全特性

1. **双温度阈值与硬件级熔断断电保护**：
   - **WRN TEMP**（预警温度，默认 **75°C**）：芯片最高温持续超过此温度 **30 秒**，执行插座断电保护。
   - **STOP TEMP**（急停温度，默认 **78°C**）：芯片最高温一旦达到或超过此温度，**无条件立刻切断插座电源**。
   - **绝对不自动恢复（工业安全锁）**：断电保护触发后，系统锁死保护状态，即使矿机降温也**绝不自动恢复通电**，界面出现报警标识与 `[ RESET PROTECTION LOCK ]` 手动复位按钮，必须人工排查隐患后手动解锁。
2. **通电权限密码鉴权**：
   - 只有**启动电源（Turn ON）需要输入密码**，密码固定为：`dl.general`。
   - **关闭电源（Turn OFF）无需密码**，点击即可立即切断，方便突发紧急状况下瞬间断电。
3. **折线图纵向自适应高度放缩（Adaptive Dynamic Y-Scale）**：
   - Y 轴视口范围随当前温度曲线的极值动态适配，线条在整个图表视口纵向充分展开，波形细节起伏清晰可见。
4. **无操作自动右侧对齐**：
   - 支持使用鼠标自由缩放和平移 X 轴查看历史走势。
   - 当用户停止鼠标交互超过 **6 秒** 后，视图自动恢复右侧对齐（重置至当前时间视口 `[-3600, 0]`）。
5. **交互式垂直标线（Crosshair Cursor）与四线测温**：
   - 鼠标在折线图内移动时，自动显示一条白色虚线垂直参考标线。
   - 顶部状态栏同步精确显示该标线时间点对应的 **4 条线温度数值**（进水温、出水温、芯片最高温、芯片均温）及距今时间差（如 `[-15m 20s] In:40.0°C | Out:46.0°C | MaxChip:68.0°C | AvgChip:64.3°C`）。
   - 鼠标离开图表区域后垂直标线自动隐藏，恢复为当前实时温度。
6. **界面极简统一**：
   - 程序窗口与内嵌标题统一为 **`AntMinerTab`**。
   - 纯方形直角几何设计（0px Border-Radius）。

---

## 2. 界面卡片与排布

- **顶部 5 张核心卡片**：
  1. `REAL-TIME HASHRATE`：实时 5 秒算力（GH/s）
  2. `ACCEPTED SHARES`：矿池累计接受有效份额
  3. `REJECTED SHARES`：拒绝份额及拒绝率（%）
  4. `SMART PLUG POWER`：米家插座实时功率（W 与 kW，常驻常亮不掉线）
  5. `PLUG SWITCH`：插座工作状态与交互开关按钮（`[ ON ]` / `[ OFF ]`）
- **左侧图表区**：过去 1 小时 4 条平滑温度曲线，采用真实本地时钟时间轴（HH:MM / HH:MM:SS），支持垂直游标查温。
- **右侧传感器与控制区**：
  - `WRN TEMP` 与 `STOP TEMP` 双微调输入框
  - PCB 表面 6 处测温点与芯片 Die 核心 6 处测温点的方形电平仪表柱。

## 3. 运行方式

```bash
# 1. 启动桌面图形监控窗口 (PyQt5)
python antminer_gui.py

# 2. 启动 Web 监控服务 (端口 20000，开箱即用默认开启密码保护)
python antminer_web.py
# 默认直接运行即可，自动读取当前目录下的 config.json 配置文件：
# - 登录网页密码：默认为 antminer（无需输入用户名）
# - 通电操作密码：默认为 dl.general

# 3. 一键停止所有旧进程与释放 20000 端口
./stop.sh       # Linux / Ubuntu
stop.bat        # Windows
```

### 配置文件 `config.json` 说明
Web 服务启动时会自动加载并常驻读取同目录下的 `config.json`：
```json
{
  "login_password": "antminer",
  "power_password": "dl.general"
}
```
* `login_password`: Web 页面及 API 访问登录密码。在浏览器登录弹框中，**用户名无需填写（可留空或随意输入）**，只需填入该密码即可进入。
* `power_password`: 网页端点击开启插座通电时的授权密码。
